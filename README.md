## Sample Pseudocode: Decimal to Binary 

``` 

START
      INPUT decimalNum
      SET binaryResult =””

        IF decimalNum == 0

THEN

	SET binaryResult = “0”

      ELSE

	WHILE decimalNum > 0 DO

		SET remainder = decimalNum MOD 2

		SET binaryResult = remainder + binaryResult 

		SET decimalNum = decimalNum DIV 2

	ENDWHILE

      ENDIF


      DISPLAY binaryResult

END
